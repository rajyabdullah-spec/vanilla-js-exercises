Advanced JS: Functions Logic

This assignment covers Arrow Functions, Destructuring, and this keyword.

Check the browser console (F12) to see the detailed execution of the code.

Exercises:

  • Check Age: Refactored using arrow functions and ternary operator.
  • Power (pow): Calculates x to the power of n.
  • Ask Function: Arrow function callbacks.
  • Calculator: Object with read, sum, and mul methods.
  • Min: Returns the least of two numbers.
