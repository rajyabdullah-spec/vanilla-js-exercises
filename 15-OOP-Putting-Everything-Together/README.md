# 15. OOP - Putting Everything Together

This project serves as a practical implementation of fundamental Object-Oriented Programming (OOP) concepts and asynchronous programming in modern JavaScript (ES6).

## Key Concepts Applied

* **Classes:** Utilizing `class` and `constructor` to create structured blueprints for objects, ensuring clean data organization.
* **The 'this' Keyword:** Mastering the dynamic execution context using the `.call()` method to explicitly bind `this` to specific objects.
* **Promises:** Implementing asynchronous operations using `Promise` and `setTimeout`, allowing for effective handling of time-based tasks without blocking execution.

## Engineering Notes

The objective of this exercise was to bridge the gap between theoretical OOP patterns and real-world asynchronous JavaScript development. By combining these concepts, I have practiced:
1.  Encapsulating logic within classes.
2.  Managing scope and context effectively.
3.  Handling non-blocking operations using Promises, which is a critical skill for building scalable applications.
